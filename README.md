# Java Básico — Exceptions, Collections, Generics e Lambda

Este repositório reúne minhas resoluções dos exercícios da apostila Java Básico — Parte 5.

## Conteúdos praticados

- Tratamento de exceções
- Uso de coleções
- Tipos genéricos
- Expressões lambda

## Como executar

Abra o projeto no IntelliJ IDEA, escolha o exercício e clique em **Run** ao lado do método `main`.
